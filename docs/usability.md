# 可用性设计说明

## 一、界面一致性

- **统一导航**：五页共享同一顶部导航（品牌 ⚓ 海疆纵横 + 五个模块链接），当前页自动高亮（红色胶囊底色），用户随时知道自己在哪里、能去哪里；
- **统一配色**：全站 CSS 变量定义海军蓝主题（`--navy-700/800`、`--sea-100/200`、信号红 `--signal`、金色 `--gold`），卡片、按钮、徽标、时间线均取自同一变量表；
- **统一版式**：所有页面遵循 nav → page-hero → main → footer 骨架；卡片统一 `card-header / card-body / card-footer` 结构；看板网格统一 12 列 `kanban-board` 栅格；
- **统一交互语言**：筛选按钮选中态均为深蓝底白字圆角胶囊；三态提示（加载 ⚓ / 空 🪶 / 错 ⚠️）在历程、装备、首页、统计四类内容区使用同一 `renderState()` 输出，样式与文案风格一致。

## 二、操作提示

- 装备关键词筛选框自带 placeholder「舰名/舷号」，直接告知可输入内容；
- 历程模块标签栏带「类别筛选：」标签文字；筛选条右侧实时显示「共 N 艘」计数，操作结果即时可见；
- 按钮文案使用动宾结构并指示去向：「进入历程模块 →」「查看全部装备 →」「重置」；
- 数据加载中显示「⚓ 数据加载中…」占位提示，避免白屏等待焦虑；
- 三维页底部常驻提示条「鼠标拖拽环视 · W/A/S/D 移动 · 场景含航母/驱逐舰/核潜艇/两栖舰等模型」，进入即知操作方式；
- 移动端导航折叠为汉堡菜单（Bootstrap `navbar-toggler`），符合手机操作习惯。

## 三、错误提示

三层防护，均给出**下一步建议**而非只报错：

1. **断网提示**：`common.js` 监听 `online/offline`，断网时顶部黄条「⚠️ 当前处于离线（断网）状态：本站所有资源已本地化，可继续浏览」；同时导航区徽标切换为「网络：离线（断网）」。证据：[offline-notice.png](../screenshots/offline-notice.png)；
2. **请求失败（网络失败/HTTP 非 200）**：统一 `loadNavyData()` 封装 catch 后返回 `{ok:false, msg}`，内容区显示「⚠️ Failed to fetch / HTTP 500」等具体原因，不抛未捕获异常。证据：[network-error.png](../screenshots/network-error.png)；
3. **数据为空**：筛选无结果显示「🪶 没有符合筛选条件的装备，请调整筛选条件」并同步计数「共 0 艘」；历程类别为空显示「该类别下暂无历程记录」。证据：[empty-data.png](../screenshots/empty-data.png)。

非法输入（特殊字符、超长串、疑似标签 `<script>`）不会导致脚本注入或界面崩溃——关键词按普通文本参与 `indexOf` 匹配，因 `textContent/innerHTML` 场景中用户输入仅作为匹配串而非未转义直插内容区，最坏结果为空态提示。证据：[invalid-input.png](../screenshots/invalid-input.png)。
