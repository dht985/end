## 二、逐条处理记录

### R1 统计数字写死 → 采纳 ✅
**处理**：将 `index.html` 中四个统计数字改为在 `loadNavyData` 回调中从 `data.summary` 与数组长度动态赋值（`s-year/s-eq/s-ms/s-type`）。
**验证**：修改后刷新页面，数字随 data.json 自动更新。

### R2 舰船图标区分度 → 部分采纳 🟡
**处理**：为航母、核潜艇、其他舰种设计了三套不同的 SVG 轮廓（航母有斜角甲板+舰岛，潜艇为椭圆+围壳，其他为通用舰体），并按舰种给卡片顶部上色条（红/蓝/绿/紫/金/灰）。
**说明**：受限于纯 SVG 手绘复杂度，无法做到高度拟真，但类别区分已明显改善。

### R3 手机端详情面板 → 采纳 ✅
**处理**：在 `style.css` 的 `@media (max-width:768px)` 中，将详情面板移至时间线上方（`order` 调整），并增加节点点击后自动滚动到详情的行为。
**验证**：375 宽度下点击节点，详情在上方展开，无需大幅滚动。

### R4 三维阴影 → 拒绝 ❌
**理由**：A-Frame 默认光影已通过 `directional` + `ambient` 双光源提供基础明暗，移动端开启实时阴影会显著降低帧率。作为原型展示，当前视觉效果可接受，优先保证流畅度。
**备注**：期末正式版可考虑开启 `castShadow`。

### R5 README 补充说明 → 采纳 ✅
**处理**：在 README「运行说明」中补充"直接双击打开可能因浏览器本地 fetch 限制导致数据未加载，推荐用本地服务器"。

### R6 图表数据来源 → 采纳 ✅
**处理**：在 `stats.html` 页脚补充"单位：艘/吨 · 数据来源：公开资料整理"，并在每个图表的 tooltip 中明确单位。
