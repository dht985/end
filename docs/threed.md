# 三维展示与主题关联

## 一、三维场景截图

见 [screenshots/threed-showcase.png](../screenshots/threed-showcase.png)（全屏整页）：海上编队场景，含飞行甲板带舷号"16"的航空母舰、055 风格驱逐舰、核潜艇、两栖攻击舰、综合补给舰五组模型，以及海面、天空、双向光照与航标浮标装饰。

## 二、主题关联说明：为什么这个作品需要三维展示

本作品主题是**海军装备**——舰船本身就是三维空间中的大型工程体量物，平面图片与参数表格无法传达：

1. **体量感**：航母 300 余米与护卫舰 130 余米的尺度差，在三维场景中通过甲板宽度、舰体长度的直观对比一目了然，这是"排水量 80000 吨 vs 4200 吨"数字给不了的体验；
2. **空间布局**：编队阵型（航母居中、驱逐舰护卫、补给舰殿后）是海军作战概念，只有在三维空间中才能呈现；
3. **与图表互补**：stats 页回答"多少、多大"（定量），三维页回答"长什么样、怎么布阵"（定性），两者共同完成从数据到实物的认知闭环；
4. **实现呼应**：三维模型与装备页数据一一对应——场景中五类舰船正是装备页的 5 个舰种（航母/驱逐舰/核潜艇/两栖攻击舰/综合补给舰），舰岛、舷号"16/101"、垂发装置等细节均按代表型号（辽宁舰、南昌舰）建模。

技术实现上选用 **A-Frame** 而非原生 Three.js：声明式 HTML 实体标签（`<a-box>`、`<a-cylinder>`、`<a-text>` 等）与全站"HTML + JSON 数据"的技术栈同构，用几何体组合即可建模，无需外部模型文件，保持全站离线可用与零构建约束。

## 三、交互说明

| 交互 | 方式 | 实现 |
|---|---|---|
| 环视 | 按住鼠标左键拖拽 | 相机 `look-controls` 组件 |
| 漫游移动 | 键盘 W/A/S/D 前后左右平移 | 相机 `wasd-controls` 组件 |
| 页面滚动 | 浏览器默认（场景页锁定 overflow 防止误滚出场景） | CSS `overflow: hidden` |

核心代码（three-d/showcase.html）：

```html
<a-entity position="0 5 18">
  <a-camera look-controls wasd-controls></a-camera>
</a-entity>
```

**说明**：当前未提供点击拾取与缩放交互——这是有意取舍：场景内五组舰船已带悬浮文字标签（`<a-text>` 名称标注），环视 + 漫游已覆盖"观察布局与体量"的核心目标；点击聚焦类交互列入改进计划（见 [reflection.md](reflection.md)）。场景顶部"在线/离线"徽标与断网提示条与全站一致，断网时场景照常可浏览（A-Frame 已本地化）。
