# 数据可视化：图表清单、数据核验与选型说明

| # | 图表 | 类型 | 内容 |

## 二、数据来源与正确性核验

**来源**：`data/navy-data.json` 全站唯一数据源，内容整理自公开资料（中国海军官方发布、中国军网、Wikipedia 公开条目，见 JSON `meta.source`），仅作学习展示；图表不经过任何中间计算服务，由 stats.js 直接映射 JSON 的 `stats` 段。

**核验记录（发现 2 处不一致 → 已修正）**：

核验方法：以装备卡片页 12 型装备（equipment 数组）为基准，逐项推导 stats 段应有的数值，与 JSON 原值对照。

| 检查项 | JSON 原值 | 推导值 | 结论 |
|---|---|---|---|
| 舰种构成合计 | 3+3+2+2+1+1 = 12 | 航母3/驱逐3/护卫2/核潜艇2/两栖1/补给1 = 12 | ✅ 一致，未改动 |
| 年代分布合计 | 2+1+1+1+3+6+4 = **18** | 按装备数组 era 字段：2000s:3 / 2010s:6 / 2020s:3 = **12** | ❌ 多出 5 艘且 2020s 多计 1 艘 → **修正为 3/6/3** |
| 航母最大排水量 | 68000 吨 | 福建舰「约8万吨」（装备数组最大） | ❌ 无对应舰 → **修正为 80000** |
| 其余舰种最大排水量 | 补给48000/两栖40000/驱逐12000/核潜艇11000/护卫4200 | 呼伦湖4.8万/海南约4万/南昌约1.2万/长征10约1.1万/徐州4200 | ✅ 一致，未改动 |

修正后复验：年代图三根柱 3/6/3 与首页「共 12 艘」徽标、装备页计数完全对账；排水量横向图顶部 80000 与福建舰卡片「约8万吨」一致。修正后的图表截图已重新拍摄（stats-charts.png）。此过程即「风险 4：数据口径不一致」的应对实录，详见 [plan.md](plan.md)。

## 三、选型说明

**为什么选 ECharts（而非 Chart.js）**：

1. 配置即 JSON 的声明式风格，与本项目"数据驱动渲染"的架构一致，`setOption` 换数据即可复用整套视觉配置；
2. 对中文场景友好：中文文档完善、内置中文标签排版与千分位格式化（`toLocaleString` 类效果可由 label formatter 直接定制）；
3. 渐变柱色（`echarts.graphic.LinearGradient`）、环形饼图、横向柱状等效果均为原生能力，无需插件；
4. tooltip/图例交互（axis 触发、item 触发、legend 点击显隐）开箱即用，符合看板"扫一眼 + 点一下"的阅读方式。

**为什么选这三种图表类型**：

| 图表 | 选择理由 |
|---|---|
| 柱状图（年代分布） | 年代是有序分类变量，柱高直接对比各年代装备数量，配合顶部数值标签突出"2010s 是高峰"的趋势叙事 |
| 环形饼图（舰种构成） | 展示 6 个舰种占 12 艘总量的**部分-整体**关系；空心环形中心留白使画面轻盈，图例+标签双重标注避免小扇区辨认困难 |
| 横向柱状图（排水量） | 舰种名称为 4-5 字长标签，纵向柱状会导致横轴文字倾斜挤压；横向布局让类目轴放左侧完整展示，数值量级差异（4200 → 80000）经升序排列后形成清晰梯度 |
